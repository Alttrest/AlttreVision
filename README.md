## ⚙️ Getting Started

To get a local copy up and running, follow these simple steps:

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Alttrest/AlttreVision.git
   ```
2. Navigate into the directory
   ```sh
   cd AlttreVision
   ```
3. Explore the project!
